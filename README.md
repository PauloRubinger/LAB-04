# LAB-04 — Visualização de Dados com Ferramenta de BI

**Disciplina:** Laboratório de Experimentação de Software  
**Curso:** Engenharia de Software — PUC Minas  

---

## Introdução

Business Intelligence (BI) refere-se ao processo de coleta, organização, análise, compartilhamento e monitoramento de informações que apoiam tomadas de decisão baseadas em dados. Os dashboards são artefatos que convertem grandes volumes de dados em visualizações gráficas, permitindo detectar falhas e identificar oportunidades de melhoria.

O objetivo deste laboratório é utilizar uma ferramenta de BI (**Microsoft Power BI**, **Tableau** ou **Google Data Studio**) para apresentar os resultados de experimentação, explorando os dados de TIS 6.

---

## Especificação do Dashboard

### 1. Caracterização do Dataset

A primeira parte do dashboard deve caracterizar o dataset utilizado no trabalho, apresentando as características mais relevantes dos objetos de estudo por meio de visualizações adequadas.

- Se o dataset for composto por repositórios do GitHub, apresentar dados como os coletados no Laboratório 01.
- **Importante:** caso o estudo utilize alguma característica para particionar o dataset em análises comparativas (ex: linguagens de programação, períodos de tempo), é essencial apresentar as características do dataset completo **e** dos subgrupos formados.

### 2. Questões de Pesquisa

Para cada pergunta de pesquisa proposta no GQM do trabalho, incluir uma ou mais visualizações que a responda.

- Todas as métricas propostas devem ser apresentadas de forma completa.
- O dashboard deve ser **auto-explicativo**: apresentar a pergunta e, em seguida, as visualizações que a respondem.
- Escolher adequadamente as **medidas de tendência central** para sumarizar os dados.
- As **labels dos eixos** devem ser claras e expressar a medida escolhida.
